Simple Calculator

A simple desktop calculator built using Java Swing.

 Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Graphical user interface (GUI)

 Technologies Used
- Java
- Java Swing
- IntelliJ IDEA

Description
This project is a basic calculator that performs arithmetic operations through a button-based interface. It was developed using Java Swing to create a simple graphical user interface.
